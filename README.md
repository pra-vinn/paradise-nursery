# Paradise Nursery

A React plant-shopping application built with Vite and Redux Toolkit. Browse houseplants, add plants to your cart, adjust quantities, and review the cart total.

## Features
- Landing page with a plant-themed background and a Get Started button
- About Us company information page
- Plant product listing with category, description, and price
- Add-to-cart functionality
- Shopping cart with quantity controls and item removal
- Cart subtotal and total item count
- React Router navigation and Redux Toolkit state management

## Tech stack
- React
- Vite
- React Router
- Redux Toolkit
- React Redux
- CSS

## Run locally
Install Node.js (LTS), then run:

```bash
npm install
npm run dev
```

Open the local URL printed in the terminal.
